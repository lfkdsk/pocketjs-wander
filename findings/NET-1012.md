# NET-1012：客户端关闭码与名字牌像素测试

基线：`51b1b3a`。本轮修复客户端预测 rebase 的非法主动关闭码，并补齐名字牌四个方向各自独立的像素辨识力。实现、隔离变异、全量门禁和本机三端演示均通过。

## 结论

- 预测器返回 `rebase-required` 时，客户端不再主动发送浏览器禁止的 `1012`，而是发送私有码 `4001/prediction rebase`。关闭回调仍走普通 1 秒退避，旧 predictor、pending、插值和 epoch 状态被清空后建立新连接。
- 不需要修改服务器。服务器的 close 回调不读取客户端 code/reason，只做玩家、session 和广播清理；服务器主动发送的 `1008` 是合法的对端策略关闭，保持原样。
- 核心回归测试构造 epoch 19 客户端收到 epoch 20 `STATE4`，覆盖 `frozen → reconnecting → connecting → joined`，并验证新 predictor 从零开始。
- 名字牌测试不再让亮地形冒充文字，也不再用可能被其他描边副本覆盖的普通字形邻格证明方向。replacement glyph 的空心矩形四条外侧中段互不重叠，可分别证明 left/right/up/down 那一份描边存在。

## 1. 客户端关闭码

PocketJS socket contract 限定客户端主动 close code 为 `1000` 或 `3000..4999`；框架在进入 closing 状态前同步校验。因此原来的 `1012` 会抛错，客户端已经设置的 `frozen` 状态无法靠 close callback 解除。

实现增加 `PREDICTION_REBASE_CLOSE_CODE = 4001`，rebase 分支只替换关闭码，reason 仍为 `prediction rebase`。`handleClose()` 无需增加特殊策略：`4001` 不属于拒绝 token，按既有 normal policy 重连。

全仓主动关闭调用复核：

| 调用方 | code | 结果 |
| --- | ---: | --- |
| 在线客户端：leave realm / stop / link failed / freeze-rejoin | `1000` | 合法 |
| 在线客户端：upgrade-required | `4000` | 合法私有码 |
| 在线客户端：prediction rebase | `4001` | 合法私有码 |
| 本地服务器策略拒绝 | `1008` | 服务器到客户端，合法且不改 |
| bot 默认关闭 | 默认 `1000` | 合法 |

`git grep 1012 HEAD` 现在只命中上一轮历史报告中对本缺口的记录，活动代码无 `1012`。

## 2. rebase 回归测试

严格 socket harness 保留与生产相同的主动关闭码范围，并新增延迟投递 close callback 的模式。测试明确验证：

1. epoch 19 已 joined 的客户端收到 epoch 20 snapshot；
2. `message()` 不抛错，客户端先停在 `frozen`，输入不再推进旧 predictor；
3. close request 精确为 `4001/prediction rebase`；
4. 异步 close callback 清空旧状态并安排 1000 ms normal backoff；
5. 999 ms 不连接，1000 ms 创建第二条 socket 并发送带原 ticket 的 JOIN；
6. 新 `WELCOME4` 和初始 `REGION_STATE` 后进入 epoch 20 的 `joined`，新 predictor 的 seq/unacked 都为 0。

## 3. 名字牌四向像素辨识力

旧 helper 扫描整个 160 px label，并只按 named 帧亮度判断“前景”。这会把雪地等亮背景误作白字；对普通 `Octo` 字形检查相邻暗像素时，另一个方向的描边还可能落到同一目标格，尤其造成删 left/right 仍通过。

本轮做了两层修正：

- 普通名字的四地形 smoke 只扫描真实文字横向范围，并要求前景像素相对 blank 帧确实向白色覆盖。
- 独立方向证明使用 7×8 空心 replacement glyph。每条边排除角落后，在外侧一像素中段取样；例如 left 只取 `x0-1, y0+1..y1-1`，其他三份偏移无法画到这些像素。480×272 与 960×544 下，每个 glyph cell 都分别断言 left/right/up/down 命中。

聚焦结果：

```text
bun test tests/wander-online-journey-view.test.ts --timeout 60000 -t "outline|outside the font"
3 pass / 0 fail / 316 expect
```
